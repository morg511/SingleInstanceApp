Описание проекта



Консольное приложение на C#/.NET, которое запрещает одновременный запуск нескольких экземпляров программы.



Реализованные функции



Защита от повторного запуска с помощью Mutex.

Вывод сообщения при попытке повторного запуска.

Обработка исключений с помощью try/catch.

Демонстрация использования памяти.

Освобождение ресурсов после завершения программы.



Запуск программы



Открыть командную строку в папке проекта.

Выполнить команду dotnet run.

Для проверки открыть вторую командную строку в этой же папке и повторить запуск.



Ответы на вопросы 


1\. Что такое исключение и зачем нужен try/catch?



Исключение — это ошибка, которая возникает во время выполнения программы и нарушает её обычную работу. Конструкция try/catch используется для обработки таких ошибок. Код, в котором может возникнуть исключение, помещается в блок try, а обработка ошибки выполняется в блоке catch. Это позволяет вывести понятное сообщение и избежать неожиданного завершения программы.



2\. Что такое виртуальная память?



Виртуальная память — это механизм операционной системы, который предоставляет каждому процессу собственное виртуальное адресное пространство. Она обеспечивает изоляцию процессов и позволяет операционной системе эффективно управлять оперативной памятью. В программе для демонстрации использования памяти применяется GC.GetTotalMemory(false), который возвращает приблизительный объём памяти управляемой кучи .NET.



3\. Почему один большой коммит — плохой признак самостоятельной работы?



Один большой коммит не показывает последовательность разработки проекта. По истории Git сложно определить, когда был создан проект, когда добавлялась основная логика, исправлялись ошибки и проводилось тестирование. Несколько осмысленных коммитов позволяют проследить этапы разработки и оценить изменения, внесённые в проект.
